# MatchUP
This was my final project for CS50 web track. MatchUP It is a plataform to bring the community closer. People can post their projects and/or their activities inviting more people to participate. It can be a soocer game, a volunteering project or anything else. I used HTML, CSSS, JavaScript, FLask and SQLite to complete this project. I also made it portable to mobile users.
